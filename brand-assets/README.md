# Jackpota brand accents for blog featured images

Repeating elements from the Jackpota brand kit, used in every blog featured image so the set stays consistent. The main scene of each image is designed from the post's content; these files are the accents.

- `logo.png`: official Jackpota wordmark
- `Coin-*.png`, `Group_216-000.png`: gold coins at various angles and a coin stack
- `App_Icon-*.png`: app icons

**Colors:** black `#000000` background, yellow `#FFCD36`, green `#1EE05C` / vivid green `#01FF41`, white `#FFFFFF`.
**Fonts:** Baby School Italic for headlines (not stored here; get it from dafont.com, "Baby School"), Ubuntu Bold for supporting text.
**Signature elements:** Baby School headline in white + yellow (+ green accents), glowing yellow outline box, gold coins, warm gold glow on black.

**Don't use on blog images:** green SC coins, prize amounts (GC/SC), Free Spins badges, Play Now / bonus CTAs (blog compliance rules).

See the main README's featured image rules for size and safe area.
